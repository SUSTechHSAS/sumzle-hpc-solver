# PRODUCT.md

## Register
Product UI. Design serves the task: help players and researchers turn Sumzle feedback into solver constraints, run a high-performance Rust backend, and inspect results without distraction.

## Users
- Sumzle players who want to input feedback quickly.
- HPC / algorithm learners comparing thread count, top-N search, and solver statistics.
- Maintainers validating solver behavior from a browser during development.

## Usage context
Fast, focused, sometimes in dark mode. Users need dense controls, clear state, and trustworthy numeric output more than marketing polish.

## Voice
Calm, precise, bilingual-friendly. Prefer direct labels and short helper text. No hype.

## Anti-references
Purple gradients, glassmorphism, animated gradient text, confetti, oversized marketing hero sections, emoji as primary navigation, thick one-sided card borders, generic SaaS copy.

## Success criteria
- The puzzle grid is the primary task surface.
- Constraints and solver options are grouped by intent.
- Results make recommendation, counts, performance, probabilities, and downloads scannable.
- Dark/light themes share the same semantic tokens.
- UI withstands long expressions, large result counts, and narrow screens.
